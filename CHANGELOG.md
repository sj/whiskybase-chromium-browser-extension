# Changelog

Changes per release. When a release is published, the section for its version
is added to the GitHub Release notes, below the install instructions. Start a
section with `## <version>`, for example `## 0.2.1` or `## 0.2.1 - 2026-11-20`.

## 0.2.0

- The extension only looks at a page when you click its icon, so installing it no longer asks for access to all websites.
- New setting in the popup: **Check every page automatically**. It asks for access to all websites, and then checks pages as they load, as before.
- If the extension has no access to Whiskybase, the popup says so and offers a button to allow it again.
- The bottle's bottling series on Whiskybase, when it has one, is shown after its name.

## 0.1.1

- Asks for access to www.whiskybase.com and static.whiskybase.com only, instead of every whiskybase.com subdomain.
- New icon: a Glencairn glass.
